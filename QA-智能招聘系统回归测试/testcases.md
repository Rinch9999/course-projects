# 智能招聘系统回归测试用例

## 测试范围
求职者 / 企业 / 管理员三种角色，覆盖注册、登录、岗位发布、简历投递、状态跟踪、企业审核等核心场景。共 50+ 条，下面列代表样例。

## 核心用例（代表样例）

| 编号 | 角色 | 场景 | 用例步骤 | 预期结果 |
|---|---|---|---|---|
| TC-01 | 求职者 | 登录 | 输入正确账号密码 | 登录成功，跳转岗位列表 |
| TC-02 | 求职者 | 登录 | 输入错误密码 | 提示用户名或密码错误 |
| TC-03 | 求职者 | 岗位 | 浏览/搜索岗位 | 岗位列表正确展示 |
| TC-04 | 求职者 | 投递 | 对岗位投递简历 | 投递成功，状态=SUBMITTED |
| TC-05 | 求职者 | 投递 | 查看我的投递状态 | 显示状态流转 |
| TC-06 | 求职者 | 越权 | 访问 /enterprise?action=audit | 403 拒绝（角色校验） |
| TC-07 | 求职者 | 越权 | POST 发布岗位 | 403 拒绝（仅企业可发布） |
| TC-08 | 企业 | 登录 | 正确账号密码 | 登录成功 |
| TC-09 | 企业 | 岗位发布 | 填写岗位信息提交 | 岗位创建成功，enterpriseId 取 session |
| TC-10 | 企业 | 处理投递 | 录用/拒绝投递者 | 投递状态更新，白名单校验 |
| TC-11 | 企业 | 越权 | 访问管理员功能 | 403 拒绝 |
| TC-12 | 管理员 | 企业审核 | 审核企业入驻 | 审核通过，企业状态=APPROVED，写 audit 日志 |
| TC-13 | 管理员 | 企业审核 | 拒绝企业 | 企业状态=REJECTED |
| TC-14 | 通用 | 未登录 | 直接访问受保护页面 | 跳转登录页（Filter 拦截） |
| TC-15 | 通用 | 参数类型 | 传非法 id（字符串） | 接口报参数类型错误 |

## 缺陷记录（联调发现 10+ 个，代表样例）

| 缺陷 | 类型 | 状态 |
|---|---|---|
| 投递接口 id 参数类型不匹配（前端传字符串） | 参数类型 | 已闭环 |
| 求职者可直接访问 /admin/** 未拦截 | 角色越权 | 已闭环（AuthFilter 修复） |
| 企业审核状态未同步到企业表 | 数据一致性 | 已闭环 |
| 岗位发布 enterpriseId 可被前端伪造 | 越权 | 已闭环（改为 session 取值） |
| JSP 直接输出未转义，存在 XSS | 安全 | 已闭环（esc 转义） |
