# 校园活动报名 H5（Frontend-校园活动报名H5）

对应简历「前端.pdf」项目 3。纯前端移动端：HTML5 + CSS3 + JavaScript + Git Pages。

## 目录结构
```
├── index.html        # 活动介绍 + 轮播图 + 报名表单 + 成功弹窗 + 报名列表
├── css/style.css     # 难点：媒体查询 + Flex 响应式适配
└── js/app.js         # 表单校验 + localStorage 报名数据 + 重复报名提示
```

## 对应简历要点
- **技术栈**：HTML5 + CSS3 + JavaScript + Git Pages
- **核心开发**：活动介绍、轮播图、报名表单、成功弹窗、报名列表
- **难点突破**：`style.css` 用媒体查询 + Flex 做移动端响应式；`app.js` 表单校验 + localStorage 模拟报名存储 + Git Pages 静态部署。

## 运行
直接用浏览器打开 `index.html`，或 push 到 GitHub 用 Git Pages 部署。
